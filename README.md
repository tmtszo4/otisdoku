# Otisdoku

Logikai játék a [Meowdoku](https://meowdoku.app/) mintájára – macskák helyett Otist kell megtalálni.

Szabályok: minden sorban, oszlopban és színes területen pontosan egy Otis van, és két Otis nem érhet egymáshoz (átlósan sem).

Futtatás: bármilyen statikus szerverrel, pl. `python3 -m http.server`, majd `http://localhost:8000`.
